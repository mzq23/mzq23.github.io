草稿箱

这里是唯一需要你动手的地方。 写下 .md 文件丢进来，然后双击仓库根目录的 发布博客.bat，剩下的事系统全包。

怎么分类

分类 = 文件夹名。 你在本目录下建什么子文件夹，它就算哪一类；文件夹可以多层。

_inbox/
├── 周总结/                      →  content/post/周总结/
│   └── 第十八周总结.md
├── 日常总结/研二上/              →  content/post/日常总结/研二上/
│   └── 开学第一周.md
└── 随手记.md                    →  content/post/随笔/随手记/   （直接放根下算「随笔」）

哪些字段不用管

发布时自动生成，你只写正文就行：

字段 自动取值
title 正文第一个 # 一级标题，没有就用文件名
date 文件最后修改时间
description 正文第一段，截到 80 字
categories 你放的文件夹名
tags 留空，想加就在 frontmatter 里自己写

图片、PDF 和文章放同一个文件夹，发布时会跟着一起搬走，正文里的 ![](图片名.png) 不用改路径。

两个容易踩的坑

一、标题不要写两遍。 页面上的大标题由模板统一渲染，你如果又在正文第一行写 # 同样的标题，页面上会出现两个大标题 —— 发布时会自动去掉。如果你写的这个 # 标题 比 frontmatter 里的更详细（比如带了日期区间），系统会反过来采纳它。

二、日期不要手写。 让系统取文件修改时间。如果你非要手写，一定要带时区：

date: 2026-09-14T15:50:26+08:00    # 正确
date: 2026-09-14T15:50:26          # 错误：会被当成 UTC，等于北京时间晚上 23:50

漏掉 +08:00 会让文章看起来"还在未来"，Hugo 就直接不生成那一页 —— 现象是「明明提交了，网站上却找不到」。（站点配置里已经兜底指定了东八区， 但自己写的时候还是带上更稳妥。）

这个目录不会被打包上线

文件夹名以 _ 开头，Hugo 会整个忽略它。所以你在这里写得多乱都没关系。
